## Highlights
- Private categories: titles from a private category leave no history and show only inside that category
- Technical stream info (resolution, HDR, Dolby Vision, audio, subtitles) and age rating on the detail page
- Playlist loading is more robust: cut-off downloads are detected, a "reload playlist completely" button, memory-friendly language selection
- Live TV and TV guide: Up/Down wrap around at the ends; Arabic and Polish added

## New
- Private categories (menu key or hold OK on a category > "Make private"); list under Settings > Parental controls
- Sublists per kind (Live TV, Movies, Series), export and import as JSON, default sort for lists
- Detail page: technical stream info line (can be switched off in Player settings) and age rating (FSK)
- Playlists show their channel, movie and series counts; option to keep the screen awake while browsing
- Arabic and Polish UI languages
- Trailer button opens YouTube directly

## Improved
- Search keeps the last searches in one row, "Show all" opens the full history
- Backup servers: the next server is tried also after HTTP 401, 403 and 404
- Live channels in groups named "Movies" stay in Live TV

## Fixed
- Cut-off playlist downloads are no longer stored as the playlist
- Unreadable saved playlist list is no longer overwritten
- Filter on group names containing "|" works again
- Unencrypted connection to a server with a wrong certificate now needs your consent

## Good to know
- Install over the old version; data is kept (same signature).
- Several of these changes are not yet tested on many devices.
